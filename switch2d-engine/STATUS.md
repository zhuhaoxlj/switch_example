## 📝 已知限制

### 1. 图像格式支持
**当前状态**：仅支持 BMP 格式  
**原因**：系统未安装 SDL2_image  
**解决方案**：
```bash
sudo dkp-pacman -S switch-sdl2_image
make clean && make
```

### 2. 字体渲染
**当前状态**：TextRenderer 未完全实现  
**原因**：需要 SDL2_ttf 库  
**影响**：低，可使用图片字体替代

### 3. 高级渲染
**当前状态**：无 Shader 支持  
**原因**：使用 SDL2 渲染器  
**影响**：低，2D 游戏足够使用

## 🎯 使用案例

### 适合制作的游戏类型
1. ✅ **平台跳跃游戏**（如 Celeste）
2. ✅ **射击游戏**（如 Space Invaders）
3. ✅ **益智游戏**（如 Tetris）
4. ✅ **动作游戏**（如 Hyper Light Drifter）
5. ✅ **休闲游戏**（各种小游戏）

### 不适合的项目
- ❌ 3D 游戏（使用 deko3d 引擎）
- ❌ 需要复杂物理的游戏（考虑 Box2D）
- ❌ 大型 RPG（需要更多工具支持）
