# Space Impact 2D - 快速开始指南

## 🎮 项目概述

这是一个使用 **Switch2D 游戏引擎**开发的横向射击游戏，移植自经典的 Space Impact 游戏。

## 📁 项目结构

```
SpaceImpact2D/
├── source/
│   ├── main.cpp           # 游戏主程序和场景
│   └── GameComponents.h   # 游戏组件定义
├── romfs/                 # 资源文件夹（精灵、音效等）
├── Makefile               # 构建配置
├── build.sh               # 构建脚本
└── README.md              # 项目说明
```

## 🚀 快速编译

### 方法 1: 使用构建脚本（推荐）

```bash
cd switch2d-engine/games/SpaceImpact2D
chmod +x build.sh
./build.sh
```

### 方法 2: 直接使用 make

```bash
cd switch2d-engine/games/SpaceImpact2D
make
```

## 🎯 游戏功能

### ✅ 已实现的功能

1. **玩家控制**
   - 方向键/左摇杆：移动飞船
   - A/B 按钮：射击
   - 边界限制和流畅移动

2. **射击系统**
   - 玩家可以发射子弹
   - 敌人会自动射击
   - 射击冷却时间控制

3. **敌人系统**
   - 自动生成敌人
   - 敌人从右侧进入
   - 敌人会射击和移动
   - 不同的生命值

4. **碰撞检测**
   - 玩家子弹 vs 敌人
   - 敌人子弹 vs 玩家
   - 敌人 vs 玩家

5. **游戏状态**
   - 分数系统
   - 生命值系统（3条命）
   - 无敌时间和闪烁效果
   - UI 显示（生命值和分数）

6. **视觉效果**
   - 滚动背景
   - 颜色区分（玩家绿色、敌人红色）
   - 无敌闪烁效果

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| 方向键/左摇杆 | 移动飞船 |
| A 按钮 | 射击 |
| B 按钮 | 射击 |
| + 按钮 | 退出游戏 |

## 🔧 游戏组件架构

### 核心组件

1. **GameManager** - 游戏管理器
   - 管理分数、生命值和游戏状态

2. **PlayerController** - 玩家控制器
   - 处理玩家输入
   - 控制移动和射击
   - 无敌状态管理

3. **Enemy** - 敌人组件
   - 敌人行为和射击
   - 生命值管理

4. **Bullet** - 子弹组件
   - 子弹移动逻辑
   - 区分玩家/敌人子弹

5. **EnemySpawner** - 敌人生成器
   - 定时生成敌人
   - 随机位置

6. **BackgroundScroller** - 背景滚动
   - 创建无限滚动效果

7. **UIRenderer** - UI 渲染器
   - 显示生命值和分数

## 📝 开发说明

### 扩展游戏

如果想添加新功能，可以：

1. **添加新武器**
   - 在 `GameComponents.h` 中创建新的武器组件
   - 修改 `PlayerController::shoot()` 方法

2. **添加新敌人类型**
   - 创建新的 Enemy 子类
   - 在 `EnemySpawner` 中添加生成逻辑

3. **添加关卡系统**
   - 在 `GameManager` 中添加关卡管理
   - 根据关卡调整难度

4. **添加音效**
   - 在 `romfs/sounds/` 中添加音频文件
   - 使用引擎的 AudioManager 播放

5. **添加图形资源**
   - 在 `romfs/sprites/` 中添加图片
   - 使用 `SpriteRenderer` 显示

### 代码风格

- 使用 C++17 标准
- 遵循 Switch2D 引擎的组件模式
- 每个游戏对象通过添加组件来获得功能
- 使用 `onStart()`, `onUpdate()`, `onRender()` 生命周期方法

## 🐛 已知问题
