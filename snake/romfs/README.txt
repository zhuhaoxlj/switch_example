音频文件说明 / Audio Files
===========================

请将以下音频文件放置在此目录中：
Please place the following audio files in this directory:

【音效文件 / Sound Effects】
1. eat.wav - 吃到食物时的音效 (Sound when eating food)
   - 格式 (Format): WAV
   - 建议长度 (Suggested duration): 0.5-1秒 (0.5-1 second)
   
2. gameover.wav - 游戏结束时的音效 (Sound when game over)
   - 格式 (Format): WAV
   - 建议长度 (Suggested duration): 1-2秒 (1-2 seconds)

【背景音乐 / Background Music】
3. bgm.mp3 - 游戏背景音乐 (Game background music)
   - 格式 (Format): MP3
   - 建议长度 (Suggested duration): 30秒以上，会循环播放 (30+ seconds, will loop)
   - 音量 (Volume): 游戏会自动设置为50%音量

音频文件要求 / Audio File Requirements:
【WAV 音效】
- 格式 (Format): WAV
- 采样率 (Sample rate): 44100 Hz
- 位深度 (Bit depth): 16-bit
- 声道 (Channels): 单声道或立体声 (Mono or Stereo)

【MP3 音乐】
- 格式 (Format): MP3
- 比特率 (Bitrate): 128-320 kbps
- 采样率 (Sample rate): 44100 Hz

如何获取音频文件 / How to get audio files:
1. 从免费音效/音乐网站下载 (Download from free websites):
   - freesound.org (音效)
   - zapsplat.com (音效)
   - incompetech.com (音乐)
   - bensound.com (音乐)

2. 使用音效生成工具 (Use sound effect generators):
   - BFXR (bfxr.net)
   - SFXR
   - ChipTone

3. 自己录制/创作 (Record/create your own)

音乐控制 / Music Control:
- 游戏开始时自动播放 BGM (BGM plays automatically on start)
- 暂停游戏时 BGM 也会暂停 (BGM pauses when game is paused)
- 游戏结束时 BGM 停止 (BGM stops when game over)
- 重新开始时 BGM 恢复播放 (BGM resumes on restart)

注意 / Note:
如果没有音频文件，游戏仍然可以正常运行，只是没有声音。
The game will still run without audio files, just without sound.
