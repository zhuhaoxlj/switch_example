# Snake Game for Nintendo Switch

一个经典的贪吃蛇游戏，专为 Nintendo Switch 开发。

## 功能特性

- 🐍 经典贪吃蛇游戏玩法
- 🎮 支持 Joy-Con 手柄控制
- 🔊 音效支持（吃食物和游戏结束）
- 📊 实时分数显示
- ⏸️ 暂停功能
- 🔄 游戏结束后可重新开始

## 操作说明

### 游戏控制
- **方向键（D-Pad）**: 上/下/左/右 控制蛇的移动方向
- **A 键**: 游戏结束后按此键重新开始
- **X 键**: 暂停/继续游戏
- **+ 键**: 退出游戏

### 键盘控制（用于模拟器测试）
- **方向键**: 控制蛇的移动
- **空格键**: 暂停/继续
- **R 键**: 游戏结束后重新开始
- **ESC 键**: 退出游戏

## 游戏规则

1. 控制蛇吃到红色的食物
2. 每吃一个食物，蛇会变长，分数增加 10 分
3. 游戏速度会随着分数增加而逐渐加快
4. 碰到墙壁或自己的身体会导致游戏结束

## 编译说明

确保已安装 devkitPro 和相关工具链。

```bash
make
```

编译成功后会生成 `snake.nro` 文件。

## 安装运行

1. 将 `snake.nro` 复制到 Switch SD 卡的 `/switch/` 目录下
2. 通过 Homebrew Launcher 启动游戏

## 音效文件

游戏支持以下音频文件：

### 音效（WAV 格式）
- `romfs/eat.wav` - 吃到食物时的音效
- `romfs/gameover.wav` - 游戏结束时的音效

### 背景音乐（MP3 格式）
- `romfs/bgm.mp3` - 循环播放的背景音乐（音量设为 50%）

### 添加音频文件

你可以将自己的音频文件放到 `romfs` 目录下：

1. 准备音效文件（WAV 格式）和背景音乐（MP3 格式）
2. 将它们命名为 `eat.wav`、`gameover.wav` 和 `bgm.mp3`
3. 放到 `romfs` 目录中
4. 重新编译项目

**音乐控制**：
- 游戏开始时自动播放 BGM（循环播放）
- 按 X 键暂停游戏时，BGM 也会暂停
- 游戏结束时，BGM 停止
- 重新开始游戏时，BGM 恢复播放

**注意**: 如果没有提供音频文件，游戏仍然可以正常运行，只是没有声音。

## 技术栈

- **图形渲染**: SDL2
- **音频**: SDL2_mixer
- **输入**: SDL2 Joystick API
- **语言**: C++11

## 游戏界面

- 网格大小: 20x20 像素
- 分辨率: 1280x720
- 网格数量: 64x36

## 颜色方案

- 背景: 深蓝灰色
- 蛇头: 亮绿色
- 蛇身: 绿色
- 食物: 红色
- 网格线: 灰色

## 性能优化

- 使用 VSync 保证流畅的 60 FPS
- 硬件加速渲染
- 优化的碰撞检测算法

## 技术亮点

- 实现了自定义的 5x7 位图字体系统
- 字体支持数字、大小写字母和常用标点符号（包括 @ 符号）
- 支持多行文本显示（`\n` 换行符）
- **可调节字号**：支持任意整数缩放（1x, 2x, 3x 等）
  - 标题使用 3x 字号（更醒目）
  - 正常文字使用 2x 字号（清晰易读）
  - 小字使用 1x 字号（节省空间）
